# 찢랭 (Jjit-lang)

> **"야, 이 씨발련아"** — 코딩은 이렇게 시작하는 거다.

찢랭은 모든 키워드가 순수 한국어 욕설로 이루어진 난해한 프로그래밍 언어다.
**"니 친정 엄마, 씹구멍 찢으면 좋겠니"** 라는 전설적인 구문에서 이름을 따왔다.

---

## 특징

- 모든 키워드가 한글 — 영어는 일절 사용 금지
- 숫자로만 이루어진 변수명 — 변수는 오직 숫자로 식별
- Python 인터프리터 — Python 3.10+만 있으면 어디서든 실행 가능
- 제어 흐름 — `if`/`else`, `while` 반복문, 논리 연산
- 사칙연산 — 덧셈, 뺄셈, 곱셈, 나눗셈, 나머지 연산
- 문자 출력 — ASCII 코드로 문자열 출력 가능
- 강제 패닉 — 프로그램을 우아하게 뻗을 수 있음

---

## 설치 및 실행

```bash
cd 찢랭/py
pip install .
python -m jjitlang 찢랭/examples/hello.jjit
```

설치 없이 바로 실행:

```bash
python -m jjitlang.interpreter 찢랭/examples/hello.jjit
```

## 언어 명세

### 구조

모든 프로그램은 **반드시** 다음 마커로 시작하고 끝나야 한다:

```
야, 이 씨발련아
  ... 코드 ...
니 친정 엄마, 씹구멍 찢으면 좋겠니
```

### 문법 규칙

| 규칙 | 설명 |
|------|------|
| `,` (쉼표) | 문장 내부의 요소나 인자 구분 |
| `.` (마침표) | 모든 명령 코드의 종결 — **필수** |
| 들여쓰기 | `if` / `while` 블록 — Python 스타일 |
| `#`, `//` | 한 줄 주석 |

### 변수

- 변수명은 **오직 숫자** (`1`, `2`, `3`, ...)
- 사용 전 **반드시 선언** 필요
- 모든 변수는 **정수** (기본값 `0`)
- 변수 참조 시 숫자는 변수명으로 해석됨 (리터럴 불가)

### 키워드

#### 기본 키워드

| 키워드 | 기능 | 문법 |
|--------|------|------|
| `형수` + `새끼` | 변수 선언 | `형수, 새끼, 1.` |
| `찢` | 값 대입 | `1, 찢, 10.` |
| `찢` + `놈` | 표준 입력에서 정수 읽기 | `1, 찢, 놈.` |
| `찢` + `씨발년` / `씨발년아` | `True` 대입 | `1, 찢, 씨발년.` |
| `찢` + `시발련` | `False` 대입 | `1, 찢, 시발련.` |
| `미친년` | 조건문 시작 (if) | `미친년, 1 > 2` |
| `병신` | 조건문 분기 (else) | `병신` |
| `지가 나온 구멍` | 반복문 (while) | `지가 나온 구멍, 1 > 2` |
| `칼로 쑤신다` | 1 증가 및 출력 (`++` + print) | `1, 칼로 쑤신다.` |
| `시팔련` | 논리 반전 (NOT) | `1, 시팔련.` |
| `개새끼` | 변수 메모리 해제 | `1, 개새끼.` |
| `이 인간 쓰.레.기.야` | 시스템 패닉 (강제 종료) | `1, 이 인간 쓰.레.기.야.` |

#### 출력 키워드

| 키워드 | 기능 | 문법 |
|--------|------|------|
| `불지른다` | 정수 출력 (print) | `1, 불지른다.` |
| `메롱` | 문자 출력 (ASCII → char) | `1, 메롱.` |

#### 연산 키워드

`찢` (대입) 과 함께 사용.

| 키워드 | 기능 | 문법 |
|--------|------|------|
| `드럼통` | 덧셈 (+) | `3, 찢, 1, 드럼통, 2.` |
| `죽일` | 뺄셈 (-) | `3, 찢, 1, 죽일, 2.` |
| `패륜아` | 곱셈 (*) | `3, 찢, 1, 패륜아, 2.` |
| `도련님` | 나눗셈 (//) | `3, 찢, 1, 도련님, 2.` |
| `또라이` | 나머지 (%) | `3, 찢, 1, 또라이, 2.` |
| `공작금` | 비교 (0/1 반환) | `3, 찢, 1, 공작금, >, 2.` |

### 조건식

| 연산자 | 의미 |
|--------|------|
| `>` `<` `>=` `<=` `==` `!=` | 비교 연산 |

## OJ 채점기

찢랭은 OJ(Online Judge) 채점기에서 `jjit` 언어로 사용할 수 있다.
채점기는 `찢랭/py/jjitlang/` 인터프리터를 샌드박스 내에서 직접 실행한다.

### OJ 서버 업데이트

```bash
# 최신 찢랭으로 OJ 업데이트
cd oj채점
bash scripts/update_jjit.sh
```
