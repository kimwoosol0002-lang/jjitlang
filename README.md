# 찢랭 (Jjit-lang)

**일베 아니고 DC 등 커뮤니티 안 합니다.**

> **"야, 이 씨발련아"** — 코딩은 이렇게 시작하는 거다.

찢랭은 모든 키워드가 순수 한국어 욕설로 이루어진 난해한 프로그래밍 언어다.
**"니 친정 엄마, 씹구멍 찢으면 좋겠니"** 라는 전설적인 구문에서 이름을 따왔다.

---

## 특징

- 모든 키워드가 한글 — 영어는 일절 사용 금지
- 변수명과 값은 **한글 숫자**로만 표현 — 일반 숫자(0-9) 사용 불가
- Python 인터프리터 — Python 3.10+만 있으면 어디서든 실행 가능
- 제어 흐름 — `if`/`else`, `while` 반복문, 논리 연산
- 사칙연산 — 덧셈, 뺄셈, 곱셈, 나눗셈, 나머지 연산
- 문자 출력 — ASCII 코드로 문자열 출력 가능
- 강제 패닉 — 프로그램을 우아하게 뻗을 수 있음

---

## 설치 및 실행

```bash
cd py
pip install .
python -m jjitlang examples/hello.jjit
```

설치 없이 바로 실행:

```bash
python -m jjitlang.interpreter examples/hello.jjit
```

## 언어 명세

### 구조

모든 프로그램은 **반드시** 다음 마커로 시작하고 끝나야 한다:

```
야, 이 씨발련아
  ... 코드 ...
니 친정 엄마, 씹구멍 찢으면 좋겠니
```

### 문법 규칙

| 규칙 | 설명 |
|------|------|
| `,` (쉼표) | 문장 내부의 요소나 인자 구분 |
| `.` (마침표) | 모든 명령 코드의 종결 — **필수** |
| 들여쓰기 | `if` / `while` 블록 — Python 스타일 |
| `#`, `//` | 한 줄 주석 |

### 변수

- 변수명은 **오직 한글 숫자** (`야`=1, `야이`=2, ...)
- 사용 전 **반드시 선언** 필요
- 모든 변수는 **정수** (기본값 `0`)
- 변수 참조 시 한글 숫자는 변수명으로 해석됨 (리터럴 없음)
- **일반 숫자(0-9)는 언어에서 완전히 제거됨** — 한글 숫자만 사용 가능

### 한글 숫자

찢랭은 모든 숫자를 한글 비속어/은어로 표현한다:

| 숫자 | 한글 |
|------|------|
| `0` | `일베` |
| `1` | `야` |
| `2` | `야이` |
| `3` | `이` |
| `4` | `야 씨발놈아` |
| `5` | `이 씨발놈아` |
| `6` | `야이 병신아` |
| `7` | `야 병신아` |
| `8` | `이 병신아` |
| `9` | `오피스 누나` |
| `11` | `일베 출신` |
| `12` | `짝짝이눈` |
| `13` | `정신지체아` |
| `14` | `왜 자살` |
| `15` | `기본소득` |
| `16` | `베네수엘라` |
| `17` | `날치기` |

나머지 숫자는 사칙연산으로 조합한다. (예: `10` = `일베 출신` - `야`)

### 키워드

#### 기본 키워드

| 키워드 | 기능 | 문법 |
|--------|------|------|
| `형수` + `새끼` | 변수 선언 | `형수, 새끼, 야.` |
| `찢` | 값 대입 | `야, 찢, 야이.` |
| `찢` + `놈` | 표준 입력에서 정수 읽기 | `야, 찢, 놈.` |
| `찢` + `씨발년` / `씨발년아` | `True` 대입 | `야, 찢, 씨발년.` |
| `찢` + `시발련` | `False` 대입 | `야, 찢, 시발련.` |
| `미친년` | 조건문 시작 (if) | `미친년, 야 30년동안 … ? 일베` |
| `병신` | 조건문 분기 (else) | `병신` |
| `지가 나온 구멍` | 반복문 (while) | `지가 나온 구멍, 야 30년동안 … ? 야이` |
| `칼로 쑤신다` | 1 증가 및 출력 (`++` + print) | `야, 칼로 쑤신다.` |
| `시팔련` | 논리 반전 (NOT) | `야, 시팔련.` |
| `개새끼` | 변수 메모리 해제 | `야, 개새끼.` |
| `이 인간 쓰.레.기.야` | 시스템 패닉 (강제 종료) | `야, 이 인간 쓰.레.기.야.` |

#### 출력 키워드

| 키워드 | 기능 | 문법 |
|--------|------|------|
| `불지른다` | 정수 출력 (print) | `야, 불지른다.` |
| `메롱` | 문자 출력 (ASCII → char) | `야, 메롱.` |

#### 연산 키워드

`찢` (대입) 과 함께 사용.

| 키워드 | 기능 | 문법 |
|--------|------|------|
| `드럼통` | 덧셈 (+) | `이, 찢, 야, 드럼통, 야이.` |
| `죽일` | 뺄셈 (-) | `이, 찢, 야, 죽일, 야이.` |
| `패륜아` | 곱셈 (*) | `이, 찢, 야, 패륜아, 야이.` |
| `도련님` | 나눗셈 (//) | `이, 찢, 야, 도련님, 야이.` |
| `또라이` | 나머지 (%) | `이, 찢, 야, 또라이, 야이.` |
| `공작금` | 비교 (0/1 반환) | `이, 찢, 야, 공작금, >, 야이.` |

### 조건식

| 연산자 | 의미 |
|--------|------|
| `10년동안 니가 나한테 뭔 피해를 입었어?` | == |
| `20년동안 니가 나한테 뭔 피해를 입었어?` | != |
| `30년동안 니가 나한테 뭔 피해를 입었어?` | > |
| `40년동안 니가 나한테 뭔 피해를 입었어?` | < |
| `50년동안 니가 나한테 뭔 피해를 입었어?` | >= |
| `60년동안 니가 나한테 뭔 피해를 입었어?` | <= |
