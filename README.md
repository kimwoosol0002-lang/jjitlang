# 찢랭 (Jjit-lang)

> **"야, 이 씨발련아"** — 코딩은 이렇게 시작하는 거다.

찢랭은 모든 키워드가 순수 한국어 욕설로 이루어진 난해한 프로그래밍 언어다.
**"니 친정 엄마, 씹구멍 찢으면 좋겠니?"** 라는 전설적인 구문에서 이름을 따왔다.

---

## 특징

- 🚀 **모든 키워드가 한글** — 영어는 일절 사용 금지
- 🔢 **숫자로만 이루어진 변수명** — 변수는 오직 숫자로 식별
- 📦 **Python 인터프리터** — Python 3.10+만 있으면 어디서든 실행 가능
- 🧠 **제어 흐름** — `if`/`else`, `while` 반복문, 논리 연산
- 💥 **강제 패닉** — 프로그램을 우아하게 뻗을 수 있음

---

## 설치 및 실행

```bash
cd py
pip install -e .
python -m jjitlang ../examples/hello.jjit
```

설치 없이 바로 실행:

```bash
python -m jjitlang.interpreter ../examples/hello.jjit
```

## 언어 명세

### 구조

모든 프로그램은 **반드시** 다음 마커로 시작하고 끝나야 한다:

```
야, 이 씨발련아
  ... 코드 ...
니 친정 엄마, 씹구멍 찢으면 좋겠니?
```

### 문법 규칙

| 규칙 | 설명 |
|------|------|
| `,` (쉼표) | 문장 내부의 요소나 인자 구분 |
| `.` (마침표) | 모든 명령 코드의 종결 — **필수** |
| `{ }` | `if` / `while` 블록 |
| `( )` | 조건식 감싸기 |
| `#` | 한 줄 주석 |

### 변수

- 변수명은 **오직 숫자** (`1`, `2`, `3`, ...)
- 사용 전 **반드시 선언** 필요
- 모든 변수는 **정수** (기본값 `0`)

### 키워드

| 키워드 | 기능 | 문법 |
|--------|------|------|
| `형수` + `새끼` | 변수 선언 | `형수, 새끼, 1.` |
| `찢` | 값 대입 | `1, 찢, 10.` |
| `찢` + `놈` | 표준 입력에서 정수 읽기 | `1, 찢, 놈.` |
| `찢` + `씨발년` / `씨발년아` | `True` 대입 | `1, 찢, 씨발년.` |
| `찢` + `시발련` | `False` 대입 | `1, 찢, 시발련.` |
| `미친년` | 조건문 시작 (if) | `미친년, (1 > 2) { ... }.` |
| `병신` | 조건문 분기 (else) | `병신 { ... }.` |
| `지가 나온 구멍` | 반복문 (while) | `지가 나온 구멍, (1 > 2) { ... }.` |
| `칼로 쑤신다` | 1 증가 (`++`) | `1, 칼로 쑤신다.` |
| `시팔련` | 논리 반전 (NOT) | `1, 시팔련.` |
| `개새끼` | 변수 메모리 해제 | `1, 개새끼.` |
| `이 인간 쓰.레.기.야` | 시스템 패닉 (강제 종료) | `1, 이 인간 쓰.레.기.야.` |

### 조건식

조건식은 괄호 `( )` 안에 작성하며, 다음 연산자 지원:

| 연산자 | 의미 |
|--------|------|
| `>` | 크다 |
| `<` | 작다 |
| `>=` | 크거나 같다 |
| `<=` | 작거나 같다 |
| `==` | 같다 |
| `!=` | 다르다 |

변수 참조나 논리 상수만 단독으로 써도 조건식으로 사용 가능 (truthy 검사).

## 예제

### Hello World (변수 덤프)

```python
야, 이 씨발련아
형수, 새끼, 1.
형수, 새끼, 2.
1, 찢, 72.
2, 찢, 101.
니 친정 엄마, 씹구멍 찢으면 좋겠니?
```

### 카운트다운 루프

```python
야, 이 씨발련아
형수, 새끼, 1.
형수, 새끼, 2.
1, 찢, 10.
2, 찢, 1.
지가 나온 구멍, (1 > 2) {
    1, 칼로 쑤신다.
}.
니 친정 엄마, 씹구멍 찢으면 좋겠니?
```

### 입력받고 카운트

```python
야, 이 씨발련아
형수, 새끼, 1.
형수, 새끼, 2.
형수, 새끼, 3.
1, 찢, 놈.
3, 찢, 0.
지가 나온 구멍, (1 > 3) {
    2, 칼로 쑤신다.
    1, 칼로 쑤신다.
}.
니 친정 엄마, 씹구멍 찢으면 좋겠니?
```

### If / Else

```python
야, 이 씨발련아
형수, 새끼, 1.
1, 찢, 5.
미친년, (1 > 0) {
    1, 칼로 쑤신다.
}.
병신 {
    1, 시팔련.
}.
니 친정 엄마, 씹구멍 찢으면 좋겠니?
```
